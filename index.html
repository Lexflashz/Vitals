Why Vitals?

Performance monitoring, simplified.

Traditional monitoring setups can require several applications running simultaneously. Vitals brings essential gaming performance information into one standalone overlay.

No need to configure RTSS, HWiNFO, MSI Afterburner or Steam just to see your FPS and temperatures.

  • ✓ Standalone application
  • ✓ No RTSS requirement
  • ✓ No HWiNFO requirement
  • ✓ No MSI Afterburner requirement
  • ✓ No Steam requirement
  • ✓ Automatic idle detection
